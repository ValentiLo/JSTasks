🎯 События мыши в JavaScript

📖 Что такое события мыши?

События мыши — это действия пользователя, которые происходят при взаимодействии с элементами страницы. JavaScript позволяет реагировать на эти события и выполнять определённый код.

Основные типы событий мыши:

  • click — однократное нажатие на элемент
  • dblclick — двойное нажатие
  • mousedown — кнопка мыши нажата
  • mouseup — кнопка мыши отпущена
  • mousemove — движение курсора
  • mouseover / mouseout — наведение/уход курсора
  • contextmenu — вызов контекстного меню (правый клик)

🔧 Способы назначения обработчиков событий

1. Через свойство DOM-элемента:

element.onclick = function() {
    console.log('Клик!');
};

2. Через метод addEventListener():

element.addEventListener('click', function() {
    console.log('Клик!');
});
💡 Важно! addEventListener() — рекомендуемый способ, так как он позволяет добавить несколько обработчиков на одно событие.

🎨 Класс Menu и обработка событий

В вашем коде используется класс Menu с методом handleEvent. Это мощный подход, позволяющий обрабатывать разные типы событий в одном месте:

class Menu {
    handleEvent(event) {
        switch(event.type) {
            case 'mousedown':
                console.log('Кнопка нажата');
                break;
            case 'mouseup':
                console.log('Кнопка отпущена');
                break;
        }
    }
}

let menu = new Menu();
elem.addEventListener('mousedown', menu);
elem.addEventListener('mouseup', menu);

Преимущества:

  • ✅ Весь код событий в одном месте
  • ✅ Легко добавлять новые типы событий
  • ✅ Удобно поддерживать и тестировать

💡 Полезные советы

  • 🔹 Используйте event.preventDefault() для отмены стандартного поведения браузера
  • 🔹 Свойство event.target возвращает элемент, на котором произошло событие
  • 🔹 Свойство this внутри обработчика ссылается на элемент, к которому привязан обработчик
  • 🔹 hidden = true — простой способ скрыть элемент
  • 🔹 Для отладки используйте console.log() внутри обработчиков

🎯 Заключение

Используйте классы с методом handleEvent для организации чистого и поддерживаемого кода!
